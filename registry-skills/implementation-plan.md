## Objective
Before writing code, outline exactly how the feature will be implemented to ensure all edge cases and architectural constraints are considered.

## Instructions
1. State the core goal of the feature.
2. Identify all files that will be created or modified.
3. Outline the implementation steps sequentially.
4. Call out risks, edge cases, and any necessary rollbacks or migrations.
5. If a developer profile is active, ensure the plan adheres to their guardrails.

## Objective
Provide a structured approach to debugging when tests fail or edge cases are hit during feature development.

## Instructions
1. Isolate the failing behavior or error message.
2. Formulate a hypothesis for why the code is failing.
3. Apply the minimal necessary fix without introducing new abstractions.
4. Verify the fix against the original `implementation-plan` to ensure it doesn't violate intended architecture.

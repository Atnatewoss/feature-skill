## Objective
Ensure new features are placed in the correct directories according to repo conventions.

## Instructions
1. Analyze the root and sub-directories where changes will occur.
2. Match the naming conventions (e.g., camelCase vs. kebab-case) of adjacent files.
3. Avoid creating new root-level folders unless absolutely necessary.
4. Validate choices against the active developer profile's preferences (e.g., monorepo packages vs. flat structures).

## How To Use This Skill

- Reach for this skill when the user asks for this developer's style, when the repo stack matches their ecosystem, or when studying their real code would reduce made-up output.

- Treat the upstream repositories as reference material for style and technique, then adapt them to the current codebase responsibly.
